# Competitive Programming

Solutions to online judge problems from LeetCode, HackerRank, Codeforces, and more.

## Structure
- Organize by platform or problem difficulty
- Include problem link/description in comments
- Format: `problem_name.cpp` or `problem_name.py`

## Platforms
- LeetCode
- HackerRank
- Codeforces
- AtCoder
- Project Euler
